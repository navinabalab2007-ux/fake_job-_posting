# 🧠 Fake Job Detection System

## 📌 Project Overview
This project detects whether a job posting is Fake or Real using NLP and Machine Learning.

## 🚀 Features
- Detect fake job descriptions
- Uses TF-IDF for text processing
- Machine Learning model (Logistic Regression)
- Streamlit web app

## 🛠️ Technologies Used
- Python
- Scikit-learn
- NLTK
- Streamlit

## ▶️ How to Run
```bash
streamlit run app.py
